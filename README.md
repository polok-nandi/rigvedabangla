# 📖 ঋগ্বেদ সংহিতা (বাংলা অনুবাদ) - Rigveda in Bangla JSON

স্বাগতম! এই প্রজেক্টটিতে **ঋগ্বেদ সংহিতা**-র ১০টি মণ্ডলের সম্পূর্ণ তথ্য অত্যন্ত পরিচ্ছন্ন ও সুবিন্যস্তভাবে **JSON (JavaScript Object Notation)** ফরম্যাটে প্রকাশ করা হয়েছে।开发者 এবং গবেষকদের ব্যবহারের সুবিধার্থে ১০টি মণ্ডলের জন্য পৃথক ১০টি JSON ফাইল তৈরি করে রাখা হয়েছে।

## 📜 ঋগ্বেদ সংহিতা সম্পর্কে কিছু তথ্য

* **প্রাচীনতম বেদ:** ঋগ্বেদ হলো বৈদিক সাহিত্যের প্রাচীনতম শাখা এবং বিশ্বের অন্যতম প্রাচীন ধর্মীয় ও সাহিত্যিক গ্রন্থ।
* **কাঠামো:** ঋগ্বেদ **১০টি মণ্ডলে** বিভক্ত।
* **সূক্ত ও ঋচা:** এতে মোট **১,০২৮টি সূক্ত** (১,০১৭টি মূল সূক্ত + ১১টি বালখিল্য সূক্ত) এবং প্রায় **১০,৫৮০টি ঋচা** (মন্ত্র) রয়েছে।
* **বিষয়বস্তু:** ঋগ্বেদের মন্ত্রগুলোতে মূলত অগ্নী, ইন্দ্র, বরুণ, সোম ইত্যাদি বৈদিক দেব-দেবীর স্তুতি এবং দার্শনিক ভাবনা প্রকাশ পেয়েছে।
